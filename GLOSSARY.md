# MasterCangjie

MasterCangjie is a Cangjie learning platform with scored coding and multiple-choice practice and sequential topic progression. These terms distinguish learning content, work in progress, assessment evidence, and retained achievements.

## People and account access

**Learner account**:
A learner's identity in MasterCangjie, with their profile, work, results, and learning progress.
_Avoid_: Google account, profile as synonyms for learner account

**Google identity**:
The Google account identity used to access one learner account, independently of editable contact information.
_Avoid_: Contact email, mobile number as sign-in identity

**Contact email**:
An email address held as learner contact information, separate from the Google identity used for sign-in.
_Avoid_: Login email, recovery credential

**Contact verification**:
A learner's pending request to prove ownership of a proposed contact email or mobile number before it becomes active.
_Avoid_: Account recovery, account linking

**Content maintainer**:
The person responsible for preparing and correcting the curriculum and assessments.
_Avoid_: Instructor, assessor as synonyms

## Curriculum

**Roadmap**:
The ordered learning path that groups topics into categories and defines their prerequisite sequence.
_Avoid_: Topic category, dashboard as synonyms

**Topic category**:
A named grouping of related topics with no assessment or score of its own.
_Avoid_: Topic, scored module

**Topic**:
A learning unit with lessons, one assessment type, and completion criteria.
_Avoid_: Coding problem, category

**Coding topic**:
A topic assessed through one or more coding problems.
_Avoid_: Coding problem as a synonym for the whole topic

**Multiple-choice topic**:
A topic without coding exercises, assessed through one ten-question multiple-choice activity.
_Avoid_: Lesson-only topic when it implies an unassessed topic

**Onboarding**:
The mandatory first three topics: Getting Started with Cangjie, Installing the Cangjie Toolchain, and Running the First Cangjie Program.
_Avoid_: Unscored introduction

**Coding problem**:
A programming task with instructions, starter code, and test cases used to assess a solution.
_Avoid_: Topic, test case

**Test case**:
One input or setup and its expected result within a coding problem's assessment.
_Avoid_: Question, coding problem

**Hidden test**:
A test case whose existence and pass/fail outcome are visible to learners while its assessment details and diagnostic output remain concealed.
_Avoid_: Invisible test, secret score

**Multiple-choice activity**:
A topic's assessment of exactly ten questions with one correct choice per question.
_Avoid_: Individual question as a synonym for the whole activity

**Multiple-choice question**:
One prompt and its answer choices within a multiple-choice activity, with exactly one correct choice.
_Avoid_: Activity, topic

**Assessment revision**:
A particular edition of the content and scoring criteria against which learner work is evaluated.
_Avoid_: Code version, learner attempt

## Work and evaluation

**Activity draft**:
The learner's editable code or answer selections before a particular submission is finalized.
_Avoid_: Submitted solution, recorded result

**Answer sheet**:
The set of selected or unanswered choices for all ten questions in a particular activity assessment revision.
_Avoid_: Question result, best score

**Draft conflict**:
Competing versions of the same learner's activity work that await the learner's choice of which version is current.
_Avoid_: Failed assessment, lost submission

**Unattempted coding problem**:
A problem whose starter code the learner has not edited and for which they have requested no run or validation; merely opening it is insufficient.
_Avoid_: Failing problem, unevaluated attempt

**Evaluation attempt**:
An occasion on which a particular code version is evaluated against one or more test cases.
_Avoid_: Topic submission, retry without qualification

**Individual run**:
An evaluation of one test case that supplies feedback without awarding points or a solved achievement.
_Avoid_: Batch validation, scored submission

**Batch validation**:
An evaluation of all a coding problem's tests for one code version that can produce the problem's score.
_Avoid_: Individual run, topic submission

**Current result**:
A confirmed evaluation result that applies to the work and assessment revision being considered.
_Avoid_: Latest result when it belongs to different work or assessment content

**Unevaluated attempt**:
An attempted evaluation without sufficient confirmed results to assign a score, such as a service failure.
_Avoid_: Incorrect answer, zero-score result

**Topic submission**:
A particular submitted topic attempt with fixed learner work and assessment context; once finalized, it has a confirmed score and pass/fail outcome.
_Avoid_: Code draft, individual run

**Multiple-choice submission**:
A topic submission containing the ten answer selections and their evaluated results for a multiple-choice activity.
_Avoid_: Separate second score for the same multiple-choice attempt

## Progress and achievements

**Learner-topic progress**:
A learner's retained standing in one topic, including best score evidence, completion, and earned access.
_Avoid_: Current draft, latest result

**Problem score**:
The earned and possible points from a confirmed batch validation of a coding problem.
_Avoid_: Topic score, solved achievement

**Submission score**:
The earned and possible points for one finalized topic submission.
_Avoid_: Best score, topic completion

**Best topic score**:
The highest retained finalized submission score for a learner and topic, compared by percentage while preserving its original earned and possible points.
_Avoid_: Latest attempt score, total lifetime points

**Passing score**:
A finalized topic score meeting the required threshold of at least 60 percent.
_Avoid_: Automatic multiple-choice completion

**Solved achievement**:
The retained achievement of passing every test for a coding problem in a batch validation.
_Avoid_: Individual test pass, topic completion

**Topic completion**:
An earned status reached by a passing coding-topic submission or by a passing multiple-choice submission followed by the learner marking the topic complete.
_Avoid_: Opened, read, attempted, passed as interchangeable statuses

**Earned unlock**:
The retained right to access a topic after its prerequisite topic is complete.
_Avoid_: Passing score, category completion

**Resume location**:
The topic and activity location where a learner can continue their work.
_Avoid_: Score, completion status
