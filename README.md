# MasterCangjie

Cangjie programming practice and training assessments with sequential topic progression.

Product implementation follows the [accepted documentation](docs/product.md).
Evaluator feasibility checks and reusable regression fixtures live in
[tools/evaluator](tools/evaluator/README.md). Current evidence and remaining work
are tracked in the [risk register](docs/risk-register.md).

The [coding content scaffold](content/coding/README.md) organizes future problem
items by topic and provides an unauthored problem/assessment template.
