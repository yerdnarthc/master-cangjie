Choose **Cangjie 1.0.5 LTS** to match the version used here. The SDK, or software development kit, contains the tools you need. On the official download page, select the package for your operating system and processor architecture. Follow its installation guide for any required system dependencies.

The toolchain includes the compiler and other development tools. You can add an editor extension later if you want help while writing code. The extension alone does not install the SDK.
