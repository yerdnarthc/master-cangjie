Your source code is the text you write in a `.cj` file. The compiler, `cjc`, turns that text into an executable: a program your computer can run. Compiling creates the executable. Running it is the next step.

Suppose you want your program to print a greeting. You write the instructions in an editor, compile the file, then run the executable in a terminal. The terminal shows you the output. Keep those three tools in mind: the editor is where you write, the compiler builds the program, and the terminal is where you run it.
