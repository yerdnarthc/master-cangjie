Create a file named `hello.cj` and save this example in it:

```cangjie
main(): Int64 {
    println("Hello, World!")
    return 0
}
```

Start at `main`: this is the entry point, where your program begins. The braces enclose its body. Inside, `println` prints the quoted message and adds a newline. The integer `0` returned by this example indicates successful completion. Comments beginning with `//` are notes for readers; they do not print anything.
