# Sum the Interval

## Learning objective

Practice for-in through input-dependent output.

## Prerequisites

Complete Program Structure. Read the Expressions lesson for this construct. The starter supplies console input and integer conversion; valid input is guaranteed. Basic comparison, arithmetic, assignment and range notation used in the suggested approach should be introduced in the lesson with a short example.

## Problem description and instructions

Read n. Print the sum of all integers from 1 through n, including n. When n is zero, the sum is zero.

### Suggested approach

Practice for-in. Preserve the supplied input-reading code and add your computation/output inside main. This approach is guidance; equivalent solutions with the same behavior are accepted.

## Input format and constraints

One integer n on one line; 0 <= n <= 1000. Input lines contain decimal integers without leading/trailing spaces and end with LF. There are no malformed or out-of-range test inputs.

## Output format

The integer sum. End every output line with LF, including the final line. Print no prompts, labels beyond those specified, or extra blank lines.

## Sample test cases

### case-01

Input:

```text
0
```

Output:

```text
0
```

This case checks empty interval.

### case-02

Input:


### case-03

Input:

```text
5
```

Output:

```text
15
```

This case checks ordinary interval.

## Structural requirements

None. The assessment checks successful execution and output; it does not enforce the suggested conditional or loop construct.
