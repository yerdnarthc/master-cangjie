# Hello, World!

## Learning objective

Run a Cangjie program and observe its output.

## Prerequisites

Complete the preceding Getting Started with Cangjie and Installing the Cangjie Toolchain topics.

## Problem description and instructions

It's time for you to compile and run your first Cangjie program! The editor already contains a complete Cangjie program. Run it and check that it displays the message shown below. You do not need to change the starter code.

## Input format

The program receives no input.

## Output format

Print exactly one line containing `Hello, World!`, followed by a newline. Match the capitalization, comma, space, and exclamation mark.

## Constraints

No input is required.

## Sample test case

**Case 01:** The input is empty. The output is:

```text
Hello, World!
```

The program prints the greeting on one line. This sample is the problem's single test case.

## Structural requirements

There are no additional structural requirements for this problem.
